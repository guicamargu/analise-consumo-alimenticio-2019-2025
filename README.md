# Análise de Consumo Alimentício (2019–2025)

Projeto desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) em Ciência da Computação.

## Autores

* Guilherme de Oliveira Camargo
* Thiago Araújo Costa

## Objetivo

Este projeto tem como objetivo analisar tendências de consumo no setor alimentício brasileiro entre 2019 e 2025, avaliando os impactos provocados pela pandemia de COVID-19 e identificando possíveis perspectivas futuras para o mercado.

## Base de Dados

Os dados utilizados foram obtidos a partir de fontes públicas, com destaque para:

* IBGE / SIDRA
* Indicadores do comércio varejista
* Bases tratadas para análise temporal

## Ferramentas Utilizadas

* Python
* Pandas
* Matplotlib
* Google Colab
* GitHub

## Estrutura do Projeto

### dados/

Contém os arquivos CSV utilizados nas análises e no processamento dos dados.

### notebooks/

Contém o notebook principal responsável pelo tratamento, análise e visualização dos dados.

## Principais Análises

* Evolução do consumo alimentício entre 2019 e 2025
* Impactos da pandemia no comportamento de consumo
* Análise temporal dos indicadores do setor
* Comparação entre períodos pré-pandemia, pandemia e pós-pandemia
* Identificação de tendências para os próximos anos
